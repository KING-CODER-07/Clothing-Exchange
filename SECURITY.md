# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The security of the Clothing Exchange platform and its users' data is our top priority.

If you discover a security vulnerability within this project, please follow responsible disclosure guidelines:
1. **Do NOT** open a public GitHub issue.
2. Email the maintainers directly or submit a private security advisory via GitHub Security Advisories.
3. Include detailed steps to reproduce the issue along with a proof of concept if available.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to release a patch swiftly.
